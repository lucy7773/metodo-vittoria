🇬🇧 INGLESE

SOME / ANY

Impara quando usare Some e Any.

📖 Cosa significano?

Some e Any significano:

  • ✔ alcuni
  • ✔ alcune
  • ✔ un po' di

Si usano con nomi numerabili e non numerabili.

✅ Quando si usa SOME?

Some si usa soprattutto nelle frasi affermative.

Inglese Italiano
I have some friends. Ho alcuni amici.
There is some milk. C'è del latte.
She bought some apples. Ha comprato delle mele.

❌ Quando si usa ANY?

Any si usa nelle frasi negative e nelle domande.

Inglese Italiano
I don't have any money. Non ho soldi.
Do you have any brothers? Hai fratelli?
Is there any water? C'è dell'acqua?

⭐ Eccezione

Nelle offerte e nelle richieste educate si usa spesso Some anche nelle domande.

Inglese Italiano
Would you like some tea? Vuoi del tè?
Can I have some water? Posso avere dell'acqua?

📊 Schema veloce

Parola Quando si usa
Some Frasi affermative.
Any Domande e frasi negative.

✏️ Esempi

I have some books.
Ho alcuni libri.

She has some juice.
Lei ha del succo.

Do you have any homework?
Hai compiti?

We don't have any milk.
Non abbiamo latte.

Would you like some cake?
Vuoi un po' di torta?

⚠️ Errori da evitare

  • ❌ I don't have some money.
  • ✅ I don't have any money.
  • ❌ Do you have some brothers?
  • ✅ Do you have any brothers?
  • ✅ Would you like some coffee?

💡 Da ricordare

  • ✅ SOME → frasi affermative.
  • ✅ ANY → domande.
  • ✅ ANY → frasi negative.
  • ✅ SOME → offerte e richieste educate.
